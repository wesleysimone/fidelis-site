# Mensagens para o grupo de testes (WhatsApp)

## Versão A — agora (sem hospedagem, cada aparelho guarda o seu)

```
Pessoal, novo protótipo para testar: *site da FIDELIS Contabilidade & Consultoria* 🧪

👉 https://wesleysimone.github.io/fidelis-site/

Não precisa de código nem baixar nada. Na primeira vez o site pede seu nome, que é para eu saber quem mandou cada coisa.
*Pode testar à vontade: nada é real* (telefones e endereço são de exemplo e nenhuma mensagem é enviada de verdade para o cliente).

*🧪 TESTES* (botão na barra amarela)
• *Teste automático:* toque em *Iniciar teste automático* e espere cerca de 1 min. No fim aparece o relatório: toque em *📤 Enviar relatório pelo WhatsApp* e mande para mim.
• *Teste manual:* toque em *🔴 Iniciar teste* e use o site normalmente (menu, serviços, formulário de orçamento, dúvidas, Como chegar). Viu algo estranho? Toque em *📝 Anotar problema*. No fim, *⏹ Finalizar* e envie o relatório.
• Testem no *celular* principalmente!

*💡 SUGESTÕES*
• *💡 Sugestões* › *＋ Nova* › *🎯 Marcar na tela* (toque no ponto) › escreva › *Salvar sugestão*
• Na aba *Lista* você vê as suas
• No fim: *📤 Enviar minhas sugestões* › *Enviar e abrir o WhatsApp* › mande para mim

Cada sugestão ganha um número (ex.: *#003*). Quando eu ajustar, aviso aqui pelo número para vocês conferirem ✅
```

_(usem este link com o código, uma vez só já basta: o aparelho guarda)_

*O que mudou:*
• As sugestões vão *direto para o sistema*: não precisa mais mandar pelo WhatsApp.
• Antes de criar uma nova, vejam se alguém já pediu algo parecido. Se for igual, toquem em *👍 É a mesma* (evita duplicadas).
• *Aprovação:* quando eu terminar um ajuste, ele aparece em *Para aprovar*. Toquem em *👁 Ver este ponto*, confiram e escolham *👍 Aprovar* ou *✋ Pedir ajuste*.

Os testes 🧪 continuam iguais.
